# AURA TV 2.0 — مشروع Android TV التجريبي

هذه نسخة **قابلة للبناء** من واجهة AURA TV التي اعتمدتها. تعمل كتطبيق Android TV أصلي على TCL Android TV 14. لا تحتاج WebView أو تسجيل حساب أو أذان.

## الملفات الأساسية

- `app/src/main/java/com/auratv/launcher/MainActivity.kt` — تشغيل التطبيقات والإعدادات والطقس.
- `app/src/main/java/com/auratv/launcher/AuraHomeView.kt` — الواجهة، البطاقات والتنقل بالريموت.
- `app/src/main/assets/` — خلفيات KAFD وعدة أوضاع جوية، ملصقات العرض التجريبية.
- `.github/workflows/build-apk.yml` — بناء APK عبر GitHub Actions.
- `design/approved-reference-CONCEPT.png` — صورة التصميم المعتمد، وهي مرجع بصري وليست لقطة فعلية من التطبيق.

## ما يعمل في هذه النسخة

1. واجهة بمشهد كافد ليلي مع اسم محمد وشعار الشيطان الأحمر صغيرًا في الزاوية.
2. شريط جانبي: الشبكة / الرئيسية / الإعدادات فقط.
3. التنقل بأزرار الاتجاهات وOK بالريموت.
4. تشغيل تطبيقات Netflix / YouTube / Prime Video / Apple TV / Disney+ إن كانت مثبتة على TCL.
5. قائمة «كل التطبيقات» من التطبيقات المثبتة فعلاً.
6. الساعة والتاريخ من نظام التلفزيون.
7. درجة حرارة الرياض إن توفر الاتصال بخدمة Open-Meteo؛ عند انقطاع الإنترنت تظهر علامة (—) ولا نخترع درجة حرارة.
8. خيارات خلفيات كافد: تلقائي، صباح، غروب، ليل، مطر، غيم. في الوضع التلقائي يتغير المشهد حسب الساعة وحالة الطقس المتاحة.
9. بطاقة المباريات بنفس الروح البصرية المعتمدة مع **تنبيه واضح أنها بيانات تجريبية**.

## ما لم يُنفذ بعد

- جلب الخصم والموعد المباشر لمباراة مانشستر يونايتد من مزود مباريات موثوق.
- توصيات Netflix الشخصية أو قائمة «أكمل المشاهدة» من حسابك؛ لا توجد واجهة عامة رسمية تتيح الوصول التلقائي إلى هذه البيانات. الملصقات هنا صور تجريبية، والضغط يفتح Netflix نفسه.
- تحويل التطبيق إلى Launcher الافتراضي على TCL؛ يعتمد على خيارات نظام التلفزيون. لا تحذف واجهة TCL الأصلية.

## طريقة وضع المشروع في GitHub

### عبر GitHub Desktop — الأسهل على Windows

1. افتح GitHub Desktop، اختر **File → Clone repository** واختر المستودع `mohasubihi/AURA-TV`.
2. افتح مجلد المستودع على الكمبيوتر.
3. انسخ **كل محتويات** مجلد `AURA_TV_V2` إلى مجلد المستودع، ووافق على استبدال الملفات (انسخ مجلد `.github` أيضاً).
4. ارجع إلى GitHub Desktop، اكتب `AURA TV 2.0` واضغط **Commit to main** ثم **Push origin**.
5. في GitHub افتح **Actions → Build AURA TV APK** وانتظر نجاح البناء.
6. من قسم Artifacts نزّل `AURA-TV-V2-APK.zip` وفك الضغط إلى `app-debug.apk`.

### في حال فشل البناء

GitHub Actions هي وسيلة الاختبار الفعلية؛ هذه البيئة لم تتوفر فيها حزم Android SDK/Gradle لبناء APK محليًا. أرسل رسالة الخطأ من خطوة Build APK لنصلحها على ملف محدد.

## تثبيت نسخة V2 على TCL

أنت سبق وأقرنت التلفزيون بالكمبيوتر باستخدام ADB. تحقق من الاتصال قبل التثبيت:

```powershell
.\adb.exe devices
```

قد تفشل محاولة تحديث التطبيق القديم بسبب اختلاف مفتاح توقيع APK التجريبي بين تشغيلات GitHub Actions. عند ظهور `INSTALL_FAILED_UPDATE_INCOMPATIBLE` احذف **AURA TV القديم فقط** ثم ثبّت الجديد. هذا يحذف إعدادات التطبيق القديم لكنه لا يمس واجهة TCL:

```powershell
.\adb.exe -s IP:PORT uninstall com.auratv.launcher
.\adb.exe -s IP:PORT install "C:\path\to\app-debug.apk"
```

استبدل `IP:PORT` بعنوان التلفزيون الحالي الذي يظهر بحالة `device` عند تشغيل `adb devices`.

## خصوصية

لا يوجد حساب مستخدم أو تحليلات أو إعلانات. يستعلم التطبيق من Open-Meteo عن الطقس باستخدام إحداثيات عامة للرياض فقط، ولا يطلب موقع التلفزيون الدقيق.

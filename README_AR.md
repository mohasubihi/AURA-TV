# AURA TV 3.0 — نسخة Android TV أصلية

## ما الذي تغيّر؟

هذه ليست إعادة تلوين لنسخة 2.0. أزيلت طبقة الرسم اليدوي `AuraHomeView(Canvas)` وجميع صور البوسترات المركبة. واجهة 3.0 تُنشئ بطاقات مستقلة من Android Views؛ النصوص حية، الأيقونات من تطبيقات جهازك، وصور الفيديو تُحمّل مباشرة من YouTube CDN وتُقص مع المحافظة على النسب.

## الميزات الجاهزة في الكود

- خلفيات كافد تتبدل تلقائيًا بحسب ساعة التلفزيون ورمز الطقس في الرياض، مع خيار يدوي. ملفات الخلفيات 3840×2160 **تم تكبيرها من مصدر أصغر**؛ هذا ليس تصويرًا أصليًا بدقة 4K.
- الساعة والتاريخ يُقرآن من التلفزيون، والطقس من **Open-Meteo**. لو فشل الاتصال يُعرض «الطقس غير متاح» بدل درجة حرارة مختلقة.
- أحدث مقاطع قناة **Manchester United** الرسمية من موجز RSS عام، بلا مفتاح API أو تسجيل دخول. يتم تحديثها كل نحو 18 دقيقة مع إعادة طلب المحتوى عندما يعود التطبيق للعمل. بطاقة الفيديو البارز تتبدل كل 45 دقيقة، وتختلف تسمية القسم بين الصباح والنهار والليل.
- بإمكانك إضافة حتى أربع قنوات YouTube بكتابة **Channel IDs** في الإعدادات، مفصولة بفاصلة. هذا ليس ربطًا بحساب YouTube الشخصي، ولا يقرأ التوصيات أو الاشتراكات الخاصة بحسابك.
- زر الفيديو يفتح YouTube، ويجري تخزين آخر بيانات ناجحة في ذاكرة التطبيق لإعادة عرضها إن تعذر التحديث.
- بطاقة مباراة يونايتد تتطلب مفتاح API شخصيًا من **football-data.org**. يُكتب من إعدادات التلفزيون، لا تضعه في GitHub. بدون المفتاح تعرض البطاقة رابط جدول الفريق، **ولا تختلق مباراة**.
- التطبيقات تظهر بشعاراتها الفعلية من PackageManager على جهاز TCL، وكل بطاقة لها تركيز مستقل عند استخدام الريموت.
- التطبيق الجديد يحمل package ID `com.auratv.studio` لكي تستطيع تثبيته **بجانب 2.0** دون حذف النسخة السابقة.

## رفع الملفات إلى GitHub (Windows)

1. افتح GitHub Desktop للمستودع `AURA-TV` واضغط **Show in Explorer**.
2. فك ضغط `AURA_TV_V3_Github_Ready.zip`؛ انسخ **محتويات المجلد** إلى جذر مجلد `AURA-TV`، وليس مجلد ZIP نفسه. لا تحذف `.git`.
3. تأكد أن `.github/workflows/build-apk.yml` داخل الجذر، وأن `app/src/main/java/com/auratv/launcher/` يحوي `MainActivity.kt`, `RemoteData.kt`, `AuraStyle.kt`, `ImageLoader.kt`, `Models.kt`، وليس `AuraHomeView.kt` القديم.
4. في GitHub Desktop اكتب Commit: `AURA TV 3.0 Native UI` ثم **Commit to main → Push origin**.
5. افتح **Actions**، وبعد نجاح `Build AURA TV 3 APK` افتح `Summary → Artifacts` وحمّل `AURA-TV-V3-APK` وفك الضغط للحصول على `app-debug.apk`.

## تثبيت AURA 3.0 لاسلكيًا

تأكد من تفعيل Wireless Debugging في TCL ووجود الكمبيوتر معه على نفس شبكة Wi-Fi.

```powershell
# شغل هذه الأوامر من داخل مجلد platform-tools بعد فك ضغطه
.\adb.exe devices
# ضع IP:PORT من صفحة Wireless Debugging الرئيسية
.\adb.exe connect 192.168.8.5:PORT
.\adb.exe devices
# استخدم السطر الذي حالته device بدل TV_IP:PORT
.\adb.exe -s TV_IP:PORT install "$env:USERPROFILE\Downloads\AURA-TV-V3-APK\app-debug.apk"
```

بعد رسالة `Success` شغل تطبيق **AURA TV 3** من التطبيقات على التلفزيون. سيكون هناك تطبيقان منفصلان (2.0 و3.0) لتسهيل المقارنة. **لا تحذف النسخة القديمة قبل أن تتأكد من الجديدة.**

## حدود معروفة

- لا تدّعي هذه النسخة الوصول إلى حساب Netflix أو اشتراكات YouTube دون OAuth؛ الفيديوهات المعروضة عامة من قنوات تختارها.
- مع وجود اتصال دائم، قد يتأخر جلب بعض موجزات YouTube بسبب قيود الشبكة/الخدمة؛ تظهر رسالة واضحة عند الفشل.
- تبدل خلفيات كافد الحالي **نسخ تلوين للمشهد الأساسي نفسه** وليس صورًا فوتوغرافية مستقلة للصباح والمطر. الشكل يتغير ويُحافظ على نفس المباني؛ يمكن لاحقًا إنتاج خمس صور مستقلة مطابقة للمشهد.
- لم يتوفر Android SDK لاختبار بناء APK محليًا؛ اختبر على GitHub Actions، ثم على TCL. لا توجد ضمانات مطلقة قبل ذلك.
- GitHub Actions يوقّع ملفات debug بمفتاح قد يختلف في التشغيل التالي؛ لهذا أضفنا package ID جديدًا للتجربة. لتحديثات ثابتة لاحقًا، يُنصح بإعداد مفتاح توقيع محفوظ في GitHub Secrets.

## الملفات الأساسية

`MainActivity.kt`: مكونات الشاشة وأحداث الريموت والتحديث الدوري.

`RemoteData.kt`: APIs وحل RSS.

`ImageLoader.kt`: جلب صور يوتيوب مع ذاكرة صور محدودة.

`AuraStyle.kt`: مظهر البطاقات والفوكس والخطوط.

`Models.kt`: نماذج بيانات الطقس والفيديو والمباراة.

# AURA TV 3 — Native TV dashboard

See **README_AR.md** for complete Arabic installation steps, configuration and limitations.

Features: Native Android Views, genuine launcher icons from PackageManager, real YouTube channel RSS thumbnail and titles, Open-Meteo live Riyadh weather, optional football-data.org fixture integration, KAFD atmosphere switching, and D-pad focus interaction.

**This is source code, not a tested APK.** Build via `.github/workflows/build-apk.yml`.

New application ID `com.auratv.studio` allows side-by-side evaluation with V2.

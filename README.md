# AURA TV 2.0 (Android TV)

Native Kotlin + Android Canvas TV launcher preview with a visual KAFD skyline, D-pad focus, app launching, a demo football card, and stylized entertainment tiles.

Read **README_AR.md** for step-by-step deployment on TCL Android TV via GitHub Desktop, GitHub Actions and ADB.

The design image in `design/approved-reference-CONCEPT.png` is a visual concept, not a device screenshot. Real fixture and Netflix-account data are *not* integrated; demo tiles do not assert live availability. Riyadh weather is queried from Open-Meteo without personal geolocation.
